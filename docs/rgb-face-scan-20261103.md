# 영상 추정 3D 얼굴 등록

- 일반 RGB 카메라에서 추정한 MediaPipe 3D 특징점과 FaceRes 영상 특징을 함께 비교한다. 깊이 센서나 실측 거리 API는 사용하지 않는다.
- 정면 2개와 원 둘레 8구간의 서로 다른 각도 2개씩, 총 18개를 자동 수집한다. 어느 회전 방향으로 시작해도 된다. 정면으로 돌아오는 마지막 촬영은 없다.
- 각도 변화, 촬영 간격, 이동 속도와 영상 품질을 검사한다. 검출 누락이나 여러 얼굴이 보이면 수집을 보류하며 진행률을 유지한다. 저장 재시도는 이미 수집한 자료를 사용한다.
- 등록 중 실제 추정 메쉬와 구간별 진행률을 표시한다. 이 동안 손과 휴대폰 모델의 추론을 쉬어 등록 경합을 줄인다.
- 등록 형식은 schema 5다. 이전 형식의 등록은 인증에 사용하지 않으며 새로 등록한다. 다른 학습 기록은 유지한다. 기존 형식에서 갱신할 때는 이전 24시간 등록 횟수 제한 때문에 막히지 않게 한다.
- 얼굴 특징과 형상은 기존 브라우저 키·봉인·암호화 저장 경로로 보관한다. 원본 영상이나 평문 형상은 서버에 업로드하지 않는다.
- 현재 영상 특징 기준 0.8, 형상 기준 0.5와 최근 5회 중 4회 일치를 사용한다. 표시되는 백분율은 유사도이며 본인일 확률이 아니다. 실사용자·조명·카메라별 오인식률이나 위조 방어 성능은 아직 측정하지 않았다.

## 검증

- 소스 단위 테스트 343개, 자체 서버 테스트 26개 통과.
- 운영 워크스페이스 단위 테스트 49개, PostgreSQL 통합 테스트 31개 통과.
- Chromium에서 등록, 저장 실패 재시도, 재시작 후 복원, 이전 형식 재등록 테스트 통과.
- 실제 CDN 모델과 공개 얼굴 이미지로 RGB 추정 메쉬 출력 및 정면 수집 확인. 실제 사용자 카메라로 한 바퀴 등록하는 검증을 대신하지 않는다.

운영 배포 완료: `0.1.5-rgb-scan-20261103-r1`. Study·Word readiness 정상, 4개 프로세스 실행, busy=false, lastError=null 확인.

공개 사이트에서 새 schema 5 모듈과 등록 화면 코드, 18개 수집 설정을 로드했다. Edge 게스트 브라우저 초기화 오류와 요청 실패는 0건이었다. 일반·경량 실제 모델 smoke도 통과했고, 두 모드 실행 중 화면 타이머의 최대 간격은 64ms였다.
