# 얼굴 등록 지연 수정

- 운영 배포 완료: `0.1.5-face-lag-20261105-r1`.
- 얼굴 특징 추출을 카메라 Worker의 하위 Worker로 분리했다. 등록 중 특징 추출을 기다리지 않고 얼굴 추적 결과와 방향 안내를 전달한다.
- 처리 중인 등록 샘플은 하나만 유지한다. 얼굴 이탈, 다중 얼굴, 인증 초기화 이후 도착한 샘플은 폐기한다. 인식 단계는 해당 프레임의 특징 비교 결과를 계속 기다린다.
- 별도 Worker 초기화가 불가능하면 기존 Worker 내부 처리로 돌아간다. 처리 도중의 분석 오류는 인증 성공으로 처리하지 않는다.
- 모델, 224×224 입력, 원본·조명 보정 두 특징, 18개 각도, 6초 보완 수집, 품질 및 일치 기준을 유지했다.

## 검증

- 전체 단위 테스트 366개, 추가 Worker 단위 테스트 2개, 서버 테스트 69개 통과.
- 암호화 저장·재시도·재시작·계정 변경을 포함한 얼굴 브라우저 회귀 테스트 통과. 기존 브라우저 테스트의 저장 시점은 실제 6초 보완 수집 정책에 맞췄다.
- Edge에서 실제 모델의 원본·조명 보정 특징 2,048개를 직접 비교했다. 분리 전후 최대 절대 차이는 0이었다. 특징 추출 중 카메라 Worker의 타이머도 정상 실행됐다.
- 공개 참고 사진으로 실제 얼굴 모델의 등록 샘플 수집을 확인했다. 마지막 프레임의 카메라 추론 시간은 51.5ms였다. 기기 전체의 성능 수치나 이전 버전 대비 개선율을 의미하지 않는다.
- 운영 자산 7개의 SHA-256이 검증본과 일치하고, 공개 브라우저 초기화 오류는 없었다.
- 운영 서버는 새 릴리스, busy=false, lastError=null, Study·Word readiness 정상이며 네 프로세스가 모두 실행 중이다. 공개 서비스 상태 검사도 통과했다.

실제 사용자 휴대폰과 카메라를 이용한 체감 속도 및 인식률 측정은 수행하지 않았다.
