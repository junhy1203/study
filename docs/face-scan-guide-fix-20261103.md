# 얼굴 등록 완료 조건 및 방향 안내 수정

## 원인과 수정

- 기존 수집기는 정규화 반경 0.55~1.8의 좁은 타원만 받아 고개를 조금 크게 돌리면 수집을 보류했다. 속도 제한도 동일한 정규화 좌표에 고정되어 있었다.
- 8방향의 좁은 구간 안에서 서로 다른 자세를 두 번 요구해, 촬영 주기와 세로로 긴 움직임이 겹치면 같은 방향의 두 번째 자료가 계속 비었다.
- 현재 반경은 0.4~6, 구간은 겹치는 허용 범위로 검사한다. 매 프레임 최대 한 장을 수집하며, 이미 수집한 자세와 충분한 차이가 없는 프레임은 다른 구간에도 중복 등록하지 않는다. 여전히 정면 2장과 8방향 각 2장, 총 18장을 요구한다.
- 경계의 자세가 먼저 다른 구간에 배정되어 마지막 한 칸이 남는 경우, 허용 범위 안에서 기존 자료의 구간 배정을 조정한다. 이미 채워진 구간의 개수는 줄어들지 않으며, 같은 프레임을 두 구간에 중복 사용하지 않는다.
- 촬영 보류 사유를 화면에 전달한다. 얼굴 검출 및 품질 검사, 암호화 저장, 기존 본인 비교 기준은 유지한다.
- 촬영 주기와 별개로 각 얼굴 추론 프레임의 자세를 화면에 전달한다. 초록색 막대의 강조 위치와 길이가 실제 고개 방향을 따른다.
- 덜 수집된 방향은 원 바깥의 빨간 막대로 표시한다. 한 장 수집 시 옅어지고 두 장 수집하면 사라진다. 이미 완료된 방향은 초록색으로 유지한다.
- 기존 schema 5 등록은 그대로 사용할 수 있다. 이번 수정은 새 등록을 강제하지 않는다.

## 검증

- 소스 단위 테스트 346개, 운영 단위 테스트 52개 통과. 작은 원·큰 원·세로로 긴 원을 두 회전 방향 및 세 가지 시작 각도(30개 조합)로 수집하고 암호화 형식으로 보존하는 회귀 검사를 추가했다.
- 정지 화면 및 같은 자세 반복으로 전체 등록을 채울 수 없는지 검사했다.
- Edge 브라우저에서 촬영 간격 사이에도 초록색 표시가 움직이고, 등록 완료 시 빨간 표시가 모두 사라지는지 확인했다. 모바일 390px 화면에서 가로 넘침이 없고 바깥 표시가 잘리지 않는 스크린샷을 확인했다.
- 실제 사용자 카메라별 인식 성능을 측정한 결과는 아니다.

배포 완료: `0.1.5-scan-guide-20261103-r2`. 네 프로세스 실행, Study·Word 준비 상태 정상, busy=false, lastError=null 확인. 공개 Edge 브라우저에서 새 모듈, 초록색 방향 계산, 바깥 빨간 표시 계산을 확인했으며 페이지 오류·요청 실패는 0건이었다.
