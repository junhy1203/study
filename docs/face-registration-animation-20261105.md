# 얼굴 등록 애니메이션 끊김 수정

운영 배포: `0.1.5-face-smooth-20261105-r1`.

이전 수정은 특징 추출의 대기를 분리했지만 화면 안내는 여전히 400ms 이상의 카메라 분석 주기에 묶여 있었다. SVG 좌표도 관측 결과마다 즉시 바뀌어 움직임이 계단처럼 보였다.

- 등록 중 카메라 추적 간격을 80ms로 변경하고, 등록 결과 뒤의 추가 추론 휴지 시간을 제거했다. 작업 중복 금지와 새 영상 프레임 확인은 유지했다. 학습 중 분석은 기존 400ms 간격을 유지한다.
- SVG는 requestAnimationFrame에서 관측된 방향 사이를 보간한다. 특징 추출 완료가 안내를 과거 자세로 되돌리지 않게 했다.
- 바뀐 SVG 속성만 갱신한다. 얼굴 이탈, 화면 종료, 동작 줄이기 설정에서는 보간을 중단한다. 보간 결과는 얼굴 판정이나 각도 수집에 사용하지 않는다.
- 화면 배경의 흐림 필터와 수집 시 그림자 필터 효과를 제거했다.
- 등록 중 얼굴이 충분히 보일 때 불필요한 신체 자세 분석을 생략한다. 얼굴을 잃거나 작은 얼굴을 찾을 때는 기존 신체 기반 탐색을 실행하고, 등록 이후에도 기존 동작을 유지한다.

얼굴 모델, 입력 영상 해상도, 원본·조명 보정 두 특징, 특징 수집 간격, 18개 각도, 6초 보완 수집, 품질 및 일치 기준은 유지했다.

## 검증

- 전체 단위 테스트 368개 통과. 추가 얼굴 탐색 회귀 테스트를 포함한 camera-framing 테스트 5개도 통과했다.
- 등록·저장·재시도·재인식 브라우저 테스트 통과.
- 실제 얼굴 모델에서 40프레임의 등록 추적을 확인했다. 추적 약 10.7회/초, 마지막 추론 19.6ms, 최대 추론 104.8ms였다.
- 배포된 실제 SVG·CSS로 모바일 화면 크기와 CPU 6배 감속 조건에서 합성 방향 관측을 약 10회/초 전달했다. SVG의 시각 갱신은 약 93.3회/초, 프레임 간격 p95는 14.3ms였다. 초기 구간을 포함한 최대 프레임 간격은 222.5ms였다. 이는 렌더링 검증이며 실제 휴대폰 카메라 측정값이 아니다.
- 운영 파일 11개의 SHA-256이 검증본과 일치했다. 브라우저 초기화 오류와 서버 상태 오류가 없으며 공개 서비스 검사도 통과했다.
- 서버 테스트 69개, 릴리스 서명·해시 검증 통과. 새 릴리스 활성화, 모든 프로세스 실행 및 Study·Word readiness 정상을 확인했다.
