## 화면 동작

- 일반 아바타·친구 카드에서는 넓어진 시야로 큰 효과 전체를 표시.
- 가상 공간에서는 기존 캐릭터 크기를 유지하고 효과를 주변으로 크게 펼침. 캐릭터 이동 및 클릭 영역은 유지.
- 상점의 새 효과 그림을 클릭하거나 키보드 Enter/Space로 확대 미리보기. 구매나 잔액 차감 없이 확인 가능.
- 모바일 크기에 맞는 확대 대화상자, 닫기·Escape와 초점 복귀 지원.
- 움직임 줄이기 설정에서는 새 효과 애니메이션 중지.
- SVG 및 CSS 애니메이션으로 구현. 별도 프레임 반복이나 타이머 없음.

## 검증

- 배포 워크스페이스 전체 테스트 **99개 통과**.

- PC·모바일 확대 미리보기, 키보드, 미구매 상태, 움직임 줄이기 및 정리 확인.
- 기존 신화 진열·장착·액세서리 추적 회귀 검사 통과.
- 공개 서버에서도 새 효과 브라우저 검사 통과. SVG·런타임 오류 없음.
