# 아바타에서 입장하는 전체 화면 가상 공부방

플레이 화면의 별도 공부방 카드를 제거했습니다. 기존 `나의 아바타` 카드 안의 `가상현실 입장하기` 버튼으로만 연결하며, 입장 전에는 월드 위치·채팅 동기화 요청을 보내지 않습니다.

- 입장하면 브라우저 화면을 채우는 모달 창이 열립니다. 입장·퇴장 애니메이션, Escape, 나가기 버튼을 지원합니다. 퇴장·탭 이동·로그아웃 시 창과 게임 팝업을 제거하고 접속 신호를 종료합니다.
- 사선 아이소메트릭 대신 가로·세로 바닥이 정렬된 정면 위쪽 뷰입니다. 기존 방 배치·가구·아바타 장비를 유지합니다.
- PC·태블릿(700px 이상)은 오른쪽 채팅, 모바일은 아래쪽 채팅입니다. 모바일 키보드로 가시 높이가 바뀌는 경우에도 창 높이를 조정합니다.
- 인사·좋아요·박수·웃음·만세·생각·졸림·집중의 이모지 8종을 선택할 수 있습니다. 서버가 인정한 4.5초 동안 캐릭터 위에 말풍선을 표시하고, 접속한 모두에게 공유합니다.
- 친구 캐릭터를 클릭하거나 키보드로 선택해 가위바위보를 신청합니다. 친구가 수락하면 각자 손을 고르고 두 사람의 선택이 끝났을 때 동시에 공개합니다. 서버가 승패·무승부를 판정합니다.
- 게임 팝업은 등장·퇴장 애니메이션, 신청 취소·거절·재경기·닫기를 지원합니다. 선택한 손은 바꿀 수 없으며 상대 손은 결과 확정 전 API에도 공개되지 않습니다. 상대 퇴장·내보내기·응답 만료 시 게임을 종료합니다. 같은 사람은 동시에 두 게임을 진행할 수 없습니다.
- 월드·채팅·게임·이모지는 기존 0.5초 동기화를 사용하고, 요청을 순서대로 처리해 늦은 응답이 최신 상태를 덮어쓰지 않도록 했습니다.

## 검증

- 관련 단위·UI 테스트 42개 통과. 새 월드 테스트는 12개이며 이모지 검증·만료, 가위바위보 권한·수락·선택 비공개·선택 고정·승패·무승부·게임 중복 방지·퇴장·만료를 포함합니다.
- `node scripts/test-study-world-browser.mjs`: 실제 플레이 화면과 서버 서비스 구현을 연결한 두 Edge 컨텍스트로 입장 전 미접속, 전체 화면, 정면 뷰, 가구 저장, 채팅·이동, 이모지 공유·만료, 게임 신청·수락·공개·재경기·거절, 퇴장·재입장·로그아웃과 320/390/768/1024px 및 짧은 화면을 확인했습니다.
- `node scripts/test-play-browser.mjs`: 기존 아바타 꾸미기·친구 프로필·구매 등의 회귀 검증.
- 화면: `tmp/study-world-v3/desktop.png`, `mobile.png`, `rps.png`.

보조 Gemini 검토는 pre-tool 환경 훅 오류로 파일을 읽지 못했으며 성공한 검토로 집계하지 않았습니다. Codex가 구현과 직접 검증을 수행했습니다.

## 배포 상태

수정된 웹·서버·공용 모듈과 테스트를 실제 배포 원본 `multi server/apps/study`에 반영했습니다. 배포 원본의 전체 테스트 85개가 통과했습니다. 기존 서버 전용 어댑터를 보존했고 공용 웹 모듈 준비도 통과했습니다.

처음에는 명령 실행 도구에서 관리키 폴더가 보이지 않아 배포가 중단됐지만, 추가 진단에서 실제 데스크톱 호스트에는 기존 키가 정상적으로 존재하고 CurrentUser DPAPI 해제도 가능함을 확인했습니다. 기존 키가 없다고 단정했던 설명을 정정합니다. 키 생성·재발급·환경 변수 변경은 하지 않았습니다.

관리 도구에 기존 키 폴더의 명시적 경로와 프록시 없는 Windows 직접 HTTP 전송을 추가했습니다. 키 접근 문맥과 네트워크 문맥은 로컬 IPC로 연결하며, 개인키·보호 해제 값·암호는 IPC 파일에 쓰지 않습니다. 대상은 기존 Tailscale 관리 서버로 고정하고 프록시·리디렉션을 차단합니다.
