# 가구 실시간 공유와 Safari 이동 수정

- 방 주인의 현재 배치를 기존 0.5초 동기화 요청으로 공유합니다. 저장 전 추가·이동·회전·보관·변경 취소도 방문자에게 전달됩니다. 계정의 영구 배치는 기존 방 저장 버튼으로 저장합니다.
- 서버는 주인의 sync 요청에서만 배치를 받으며 기존 가구 검증을 적용합니다. 임시 배치는 주인의 접속이 유지되고 마지막 공유 후 45초 이내일 때만 사용합니다. 주인이 나가거나 공유가 만료되면 저장된 배치를 사용합니다.
- 새 가구와 겹친 참가자 위치를 서버에서 빈 칸으로 보정합니다. 클라이언트도 배치와 위치 응답의 시간차 동안 참가자를 제거하지 않고 유효한 칸에 표시합니다. 가구가 바뀌면 이전 경로의 자동 걷기를 중단합니다.
- Safari가 포커스를 body에 두는 경우에도 열린 공부방에서 키 입력을 받습니다. 물리 키 코드, 문자, 이전 keyCode와 한글 자판의 WASD 문자를 처리합니다. 채팅 입력과 별도 게임 팝업에서는 이동하지 않으며 창을 닫으면 이벤트를 해제합니다.
- 앱 → 플레이 → 가상현실 → 방 모듈 캐시 버전을 world5로 연결했습니다.

## 검증

- `node --test tests/study-world.test.mjs`: 13개 통과. 임시 배치 공유·모든 참가자의 충돌 위치 보정·방문자 배치 위조 거부·잘못된 배치 거부·프로필 보존·취소·퇴장·만료를 검증합니다.
- Edge와 Playwright WebKit에서 `scripts/test-study-world-browser.mjs` 전체 통과. 두 접속자의 저장 전 가구 추가와 취소, 겹친 아바타 표시 유지, 입장 직후·도구 포커스·body 포커스·한글 키·keyCode 대체 입력, 채팅·게임 팝업 차단 및 기존 채팅·이모지·가위바위보·화면 크기·퇴장 회귀를 포함합니다.
- WebKit 화면 크기 검사는 소수 픽셀 반올림을 고려해 0.1px 미만 오차를 허용합니다.
- 로그: `tmp/world-live-browser.log`, `tmp/world-live-webkit.log`. 변경 대상의 `git diff --check` 통과.

## 적용 상태

로컬 코드 수정과 검증 완료. 운영 서버 배포는 수행하지 않았습니다. Windows의 Playwright WebKit으로 검사했으며 실제 macOS/iOS Safari 기기 검사는 수행하지 않았습니다.
