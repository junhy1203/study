# 얼굴 비표시 등록 UI와 학습 시작 연결 오류 처리

등록 화면에서 실제 얼굴 영상·추정 메쉬·방향별 체크 목록을 제거했다. 고정된 단순 SVG 아이콘이 고개 방향을 따라 살짝 움직이고 새 각도가 수집될 때 반응한다. 수집 개수와 퍼센트, 방향을 따르는 초록 링 및 부족한 방향의 빨간 바깥 링으로 진행을 표시한다. 카메라 스트림은 등록 DOM에 연결하지 않는다. Worker의 메쉬 렌더링 및 Bitmap 전송도 제거했으며 얼굴 형상 추정과 인증·저장은 유지한다. 과거 Worker가 보낸 Bitmap은 표시하지 않고 닫는다.

`Load failed`는 응답 본문 읽기 실패와 강제 토큰 갱신 실패가 그대로 노출될 수 있는 경로를 확인하고 재현했다. 얼굴 등록 상태 읽기는 일시적인 네트워크 실패 시 한 번 재시도한다. 강제 토큰 갱신만 실패하면 여전히 유효한 캐시 토큰을 시도한다. 응답을 잃은 학습 시작 요청은 중복 저장 가능성 때문에 자동 재전송하지 않으며 한국어 연결 안내와 기존 재시도 버튼을 제공한다. 지속적인 네트워크 장애 자체가 제거되는 것은 아니다.

검증: 단위 테스트 350개 통과. Edge에서 얼굴·메쉬 표시 요소가 없는 등록 화면, 진행률, 저장 실패 후 재시도, 재시작 후 복원 검증 통과. 실제 공개 얼굴 모델의 정면 수집은 진행되고 메쉬 전송 0건·방향 피드백 4건을 확인했다. 일반·경량 Worker의 카메라 초기화와 화면 타이머, 모바일 가로 넘침 검사도 통과했다.

배포 완료: `0.1.5-private-ui-20261103-r1`. 운영 테스트 54개 및 서명·해시 검증 통과. Study·Word 준비 상태 정상, 네 프로세스 실행, busy=false, lastError=null 확인. 공개 Edge 브라우저에서 얼굴 비표시·방향 목록 제거·링·한국어 연결 안내 모듈과 새 캐시 버전을 확인했다. 브라우저 초기화 오류와 요청 실패는 0건이었다.
