# 얼굴 등록·학습 인증·폰 감지·비공개 배지 변경

## 동작

- 얼굴 등록은 수동 촬영 없이 정면·왼쪽·오른쪽·위·아래에서 4장씩, 총 20장을 모은다. 각도 변화와 최소 촬영 간격을 확인한다. 같은 자세의 반복 프레임을 추가하지 않는다.
- 인식 중단·품질 부족·여러 얼굴 검출은 진행률을 지우지 않는다. 촬영 시작 후 취소 버튼과 Escape 취소를 막고, 마지막 아래 방향 촬영으로 수집을 끝낸다. 마지막 정면 재촬영은 없다. 저장 실패 시 수집된 사진으로 저장만 다시 시도한다.
- 기존 12장 등록과 암호화 자료는 계속 읽는다. 새 20장 등록도 암호화 저장·복구한다.
- 등록된 브라우저는 서명 증명으로 인증을 갱신하며 일일 Google 재인증이나 자정 잠금이 없다. 최초 등록·교체·삭제의 계정 확인은 유지한다.
- 학습 시작 요청 전에 최초 얼굴 확인을 완료한다. 자리 이탈로 정지한 뒤 복귀할 때와 본인 확인 부족으로 정지한 뒤 재개할 때도 인증한다. 수동 정지·수면·폰 감지에 따른 재개는 별도 얼굴 인증을 요구하지 않는다.
- 인증 시도는 4초 동안 확인하고, 실패 애니메이션 후 1.5초 동안 기다린 뒤 재시도한다. 새 시도에서는 이전 비교 투표를 지운다.
- 얼굴 이탈은 기존 5초 유예 후 정지한다. 인증에는 정지 이후 새로 비교한 얼굴 근거가 필요하다.
- 최근 90초의 실제 관찰 구간 중 본인으로 확인된 시간을 계산한다. 완성된 관찰 창에서 45초 미만이면 정지하고 재인증한다. 최초 인증·재인증·수동 재개 후에는 새 90초 관찰 유예를 둔다. 미관찰 긴 구간이나 같은 타임스탬프에는 시간을 적립하지 않는다.
- 얼굴 칸에 유사도 점수의 백분율과 최근 90초 본인 인정 초를 표시한다. 유사도 점수는 신원 확률이 아니다.
- 폰 감지는 강한 근거 2회 또는 약한 근거 3회의 독립 프레임으로 확정한다. 확대 검출 사이의 낮은 전체 화면 점수는 판정 보류로 취급해 근거를 유지한다. 손바닥 랜드마크 겹침과 높은 피부 픽셀 비율이 함께 있는 후보는 감점한다.
- `ADMIM`, `Contributor`는 공개 배지 목록에 등록하지 않는다. 인증된 `tntgame1203@gmail.com`에 서버가 두 표시 배지를 부여한다. 운영 서버 시작 작업과 계정 페이지 조회에서 사용자 문서의 `privateBadges`에 저장한다. 배지는 관리자 권한을 부여하지 않는다.

## 검증

- `npm run test:unit`: 327개 통과.
- `npm run test:face:browser`: Chromium 암호화 키 보관·20장 자동 등록·저장 실패 후 재시도·브라우저 재시작·일일 재인증 생략·계정 변경 잠금 통과.
- MultiServer 전체 테스트: 35개 통과. 서명·페이로드 해시 검증 통과.
- 실제 CDN 모델의 표준·경량 WASM 추론 통과. 선명한 폰과 일부 가려진 폰의 공개 사진을 반복 추론해 모두 폰으로 확정했다. 가려진 폰은 보정 전 미확정, 보정 후 확정으로 바뀌었다.
- 390px·1280px 감지 화면 검사에서 가로 넘침 없음.
- 최종 운영 버전의 공개 계정 페이지 모듈 초기화·변경 자산 6개·모바일 가로 넘침 검사 통과. 공개 사이트 3개와 API 상태 검사도 통과했다.
