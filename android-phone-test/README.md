# Study 폰 시간 실험

실험용 Android 앱이다. 접근성 서비스를 사용해 Study 웹 화면을 표시하고, 서버가 확인한 구매 잔액에서 5분을 차감해 이용권을 시작한다. 강제 잠금이나 우회 방지를 보장하지 않는다. 차단 화면에서 실험 종료를 누르면 접근성 서비스가 꺼진다.

Android Studio에서 이 디렉터리를 열어 디버그 APK를 빌드하고 테스트 기기에 설치한다. 서버의 beginPhoneSession 배포가 먼저 필요하다. 앱에서 접근성 서비스를 직접 켜고 로그인한 후 폰 시간 5분 사용을 누른다. 재부팅 및 오프라인 처리, WebView 로그인, 접근성 권한과 스토어 정책은 실기기에서 별도로 검증해야 한다. 오프라인 상태에서 새 이용권을 발급하지 않으며, 서비스가 재시작하면 기존 이용권을 서버에서 다시 확인해야 한다.
